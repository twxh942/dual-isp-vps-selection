## 先把五个词分开：原生IP、住宅IP、双ISP、9929、4837

前三个说的是 IP 是什么，后两个说的是路怎么走。

**原生 IP**：IP 的注册地和机房物理位置一致。洛杉矶机房给的 IP，WHOIS 里国家写美国，就叫原生。原生 IP 的归属仍可能是数据中心。

**住宅 IP / 家宽 IP**：IP 归属的 ASN 是 Comcast、Charter、Cox 这类民用宽带运营商，而不是 IDC 服务商。平台查 ASN 时看到的是“某个美国家庭在上网”。

**双 ISP**：同一个 IP 在两个不同民用 ISP 名下都有注册记录。作用是当一个 ISP 的段被平台批量标记，另一个段还能撑一阵。

**9929（AS9929）**：联通 CUII 精品回程，晚高峰稳，带宽普遍被商家压在 50–100Mbps。

**4837（AS4837）**：联通 CUG 优化线路，端口能开到 1Gbps，单价更低，晚高峰波动比 9929 大一些。

四种组合摆在一起，适用人群差别很大：

| 组合 | 典型用途 | 主要代价 |

| 家宽双ISP + 4837 | 美区社媒账号、跨境电商、既要 IP 干净又要带宽 | 单价最高，Akile 这条线 ¥54.99 起 |
| 家宽双ISP + 9929 | 单账号推流、API 固定出口，对延迟敏感、对带宽要求低 | 带宽通常封在 100Mbps 以内 |
| 机房原生IP + 4837 | 建站、爬虫、中转、大流量下载 | 风控库里一眼机房 |
| 机房原生IP + 9929 | 低延迟 SSH、回国办公 | 带宽小，IP 属性不解决风控 |

## 几个还会被问到的问题

**9929 和 4837 到底怎么选？**

看你更怕延迟抖动还是更怕带宽不够。9929 晚高峰更稳，但商家普遍压在 100Mbps 以内，适合单账号推流、API 调用这类小流量场景。4837 能开到 1Gbps，适合传素材、多开、跑下载，代价是晚高峰偶有波动。Akile 这条双 ISP 线走的是 4837，如果你确实需要 9929，得去别家找。

**双 ISP 和原生 IP 是一回事吗？**

不是。原生只说明 IP 注册地和机房位置对得上，归属仍可能是数据中心。判断方法很直接：拿到 IP 后查 ASN，如果归属是 Comcast、Charter、Cox 这类民用运营商，才算家宽；再看是不是两家 ISP 都有记录，才算双 ISP。只看商家页面上的“原生”两个字，区分不出这两层。

**年付能省多少？**

从公开整理的几个 Akile 套餐看，年付价多为月付价的 10 倍，相当于免掉两个月，折下来约 83 折。但双 ISP 这条线的年付价没有公开列全，实际折扣以商品页为准。更稳的做法是先月付跑一到两周，确认 IP 属性和晚高峰延迟都对得上，再考虑转年付。
